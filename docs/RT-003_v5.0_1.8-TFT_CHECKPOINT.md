# Rentech RT-003 v5.0 — 1.8 TFT checkpoint

Status: 2026-09-16 — UI release candidate 1
Branch: `feature/rt-003-v5.0-1.8-tft`

## UI release candidate

`5.0-RC1` carries the visually accepted 160x128 layout into the real ST7735
renderer. It remains a release candidate until it is compiled, flashed and
visually checked on the physical 1.8-inch display.

RC1 scope:

- subtle black-to-deep-blue body gradient;
- segment-style primary numerals on Player, Clock, Weather and Volume;
- mirrored 4+4 brick EQ with yellow-to-green-to-blue-to-red row gradient;
- compact Bluetooth/Wi-Fi icons and explicit normal/low/absent battery states;
- Player metadata order: track title, then artist;
- larger Clock numerals, blinking colon, weekday and full calendar date;
- larger pixel-gradient weather icon, right-shifted temperature and full
  `Відчувається як` label;
- existing runtime, audio, power, SW1, ADKEY and battery measurement logic
  remain inherited from `v.4.0`.
